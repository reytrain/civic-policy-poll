# Civic Policy Poll design

Operate mode. Cool blue-gray background, white surfaces, navy actions, dark ink. A civic research workbook, not a campaign. One question per screen; clear Sheet A/B progress; large radio targets. Two-column desktop introduction, single-column mobile. Segoe UI for legibility/offline operation; 16px body, 14px labels. Ordered blue-gray-amber charts paired with counts/tables. Designed focus/error/loading/empty/reduced-motion states. Print removes navigation and uses deliberate page breaks.
